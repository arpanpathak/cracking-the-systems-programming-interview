Distributed Systems from the Ground Up

Chapter 4: Raft Leader Election and Fencing (LLD)

In Chapter 3, an operator appointed each shard’s leader manually, and when a leader failed the shard rejected every write until someone inspected follower health endpoints and promoted a survivor by hand. Meeting a 99.95% availability target permits at most 21.6 minutes of unavailability per 30-day month. No manual incident-response workflow can stay within that budget across dozens of shards. The replicas of a shard must elect their own leader automatically.

Stated concisely, automated failover sounds modest; in practice, it is the hardest algorithmic problem in this book. The members of a shard must converge on a single leader even though they communicate solely over an asynchronous network that drops and delays messages, any replica may crash and restart with only its persisted disk state, and no replica can distinguish a crashed peer from a slow or partitioned peer. Two members must never lead the same term concurrently, because split leadership would allow divergent writes. Moreover, every elected leader must already hold every write acknowledged in earlier terms so that new writes never overwrite durable client state. Reaching agreement under these fault assumptions is the problem of distributed consensus.

In this chapter, I implement the Raft consensus algorithm (Ongaro and Ousterhout, 2014) in Rust, extending the replication engine of Chapter 3 with persistent voting, term-tagged log matching, uncommitted suffix truncation, and current-term commit rules. We first build raft as a pure, clock-free, network-free state-machine library so we can drive deterministic fault injection in raftsim across 200 randomized runs of 600 steps and validate the simulator itself by disabling safety rules one by one. We then wrap raft in the networked server kvraft over gRPC and HTTP, and measure real failover pause duration under continuous write load (probe) when killing an active leader with SIGKILL.

In this chapter, we cover

  • the three Raft server roles (Follower, Candidate, Leader) and monotonic term transitions
  • volatile versus durable state (kv.log plus atomic state persistence for term and voted_for)
  • deterministic per-term election timeouts and the three-part Raft voting rule
  • zero-schema-change term markers that encode record terms inside the Chapter 2 WAL and commit inherited logs
  • Raft Log Matching (previous_term), suffix conflict resolution, and safe truncation of uncommitted records
  • the current-term commit rule and why counting replicas on earlier-term records is unsafe
  • deterministic randomized simulation (raftsim) plus fault-injection mutation testing of the simulator itself
  • kvraft: driving the pure Member state machine from a 100 ms clock task and asynchronous gRPC dispatch
  • empirical failover measurement (probe): recovering from leader SIGKILL in 1.05 s with zero lost writes

4.1 Server Roles, Terms, and Consensus Invariants

Every replica in a Raft shard runs identical code with symmetric startup arguments; no host is statically designated as leader. At any instant, each member occupies one of three roles: Follower (passive responder granting votes and appending leader batches), Candidate (transient state requesting majority votes after an election timeout), or Leader (sole writer replicating logs and broadcasting heartbeats). Figure 4-1 maps the complete server role state machine and its monotonic term transitions.

Logical time advances in discrete, strictly increasing terms starting at 1. Each term opens with an election; if a candidate secures votes from a majority of members, it leads for the remainder of that term. If votes split without a majority, the term ends with no leader and a new election starts in the next term. Building on the four replication invariants of Chapter 3, we enforce three consensus safety invariants:

No.Consensus InvariantProof Mechanism
0Election Safety: At most one member leads any given term.Each member persists at most one vote per term; any two majorities intersect in at least one member, preventing two candidates from both winning a majority.
1Leader Completeness: Every elected leader holds every record acknowledged in any earlier term.Enforced by the log-completeness voting predicate ((last_term, last_sequence) comparison) combined with quorum intersection.
2Log Safety: A member truncates a log entry only if that entry was never committed.Guaranteed by Leader Completeness together with an explicit runtime guard in Member::truncate against index <= committed.

const STATE_FILE: &str = "state";

/// Reads the term and the vote. A member that has no state file has not
/// voted and is in term 0.
fn read_state(directory: &Path) -> io::Result<(u64, Option<NodeId>)> {
    let text = match fs::read_to_string(directory.join(STATE_FILE)) {
        Ok(text) => text,
        Err(error) if error.kind() == io::ErrorKind::NotFound => return Ok((0, None)),
        Err(error) => return Err(error),
    };

    let mut fields = text
        .split_whitespace()
        .map(str::parse::<u64>);
    let invalid = || io::Error::new(io::ErrorKind::InvalidData, "the state file is malformed");
    let term = fields
        .next()
        .and_then(Result::ok)
        .ok_or_else(invalid)?;
    let voted_for = fields
        .next()
        .and_then(Result::ok)
        .map(|id| id as NodeId);

    Ok((term, voted_for))
}

impl Member {
    /// Stores the term and the vote. The new file replaces the old one in a
    /// single step, so a crash leaves one of the 2 and not a mixture.
    fn save_state(&self) -> io::Result<()> {
        let temporary = self.directory.join("state.new");
        let vote = self
            .voted_for
            .map_or(String::new(), |id| id.to_string());
        let mut file = File::create(&temporary)?;

        file.write_all(format!("{} {vote}\n", self.term).as_bytes())?;

        if self.sync {
            file.sync_all()?;
        }

        fs::rename(&temporary, self.directory.join(STATE_FILE))?;

        if self.sync {
            File::open(&self.directory)?.sync_all()?;
        }

        Ok(())
    }
}

Encoding Record Terms Without Changing the WAL Format

Raft requires the term number in which every WAL record was originally written. Rather than altering the binary record schema of Chapter 2, we encode term boundaries via an in-band term marker: the very first record every newly elected leader appends is a Put with an empty key ("") whose 8-byte little-endian value holds the leader’s term. Because the external HTTP API forbids empty keys (minimum length 1), markers can never collide with user data. Every subsequent record inherits the term of the most recent marker at or before its index. Listing 4.8 implements marker construction, marker detection, and linear-time reconstruction of the terms vector (terms_of).

Listing 4.8 In-band term markers and per-record term reconstruction in raft/src/lib.rs. raft/src/lib.rs

/// The key of a term marker. A client cannot write the empty key, so the
/// log can use it for a record of its own: the first record a new leader
/// appends, whose value is the leader's term.
const MARKER: &str = "";

fn marker(term: u64) -> Change {
    Change::Put {
        key: MARKER.to_owned(),
        value: term.to_le_bytes().to_vec(),
    }
}

/// The term a record starts, if it is a term marker.
fn marked_term(record: &Record) -> Option<u64> {
    let Change::Put { key, value } = &record.change else {
        return None;
    };

    if key != MARKER {
        return None;
    }

    let term: [u8; 8] = value.as_slice().try_into().ok()?;

    Some(u64::from_le_bytes(term))
}

/// The term of each record: the term of the last marker at or before it.
fn terms_of(records: &[Record], mut term: u64) -> Vec<u64> {
    let mut terms = Vec::with_capacity(records.len());

    for record in records {
        term = marked_term(record).unwrap_or(term);
        terms.push(term);
    }

    terms
}

4.4 Elections, Voting Safety, and Stepping Down

Deterministic Staggered Election Timeouts

A follower expects a heartbeat or Append RPC from its leader every 100 ms tick. If an entire election timeout elapses without leader contact, the follower transitions to Candidate and initiates an election. If all followers shared an identical timeout, they would stand simultaneously, vote for themselves, and deadlock in repeated split votes. In Listing 4.5, election_timeout(id, term) deterministically maps (id, term) to a value between 10 and 19 ticks (1.0 s to 1.9 s): distinct members receive staggered timeouts within each term, and each member shifts its timeout on every term increment to break accidental alignments while keeping raftsim 100% reproducible.

The Three-Part Voting Rule

A member grants its vote to a candidate if and only if three conditions hold simultaneously:

0request.term == self.term (after stepping up if request.term > self.term).Prevents stale-term candidates from collecting votes.
1self.voted_for is None or already equals Some(candidate).Guarantees at most one vote per term per member (Election Safety, invariant 0).

impl Member {
    /// A member grants its vote once in a term, and only to a candidate
    /// whose log is at least as complete as its own.
    fn on_vote(&mut self, request: VoteRequest) -> io::Result<VoteAnswer> {
        if request.term > self.term {
            self.step_down(request.term)?;
        }

        let complete =
            (request.last_term, request.last_sequence) >= (self.last_term(), self.last_sequence());
        let free = self
            .voted_for
            .is_none_or(|id| id == request.candidate);
        let granted = request.term == self.term && complete && free;

        if granted {
            self.voted_for = Some(request.candidate);
            self.save_state()?;
            self.quiet_since = self.now;
        }

        Ok(VoteAnswer {
            term: self.term,
            from: self.id,
            granted,
        })
    }

    fn on_voted(&mut self, answer: VoteAnswer) -> io::Result<Vec<Outgoing>> {
        if answer.term > self.term {
            self.step_down(answer.term)?;

            return Ok(Vec::new());
        }

        if self.role != Role::Candidate || answer.term != self.term || !answer.granted {
            return Ok(Vec::new());
        }

        self.votes += 1;

        if self.votes >= self.majority() {
            self.lead()
        } else {
            Ok(Vec::new())
        }
    }
}

Figure 4-4 demonstrates why term takes precedence over sequence length: member 2 holds a record from term 2 (reflecting progress from a later leader) and therefore defeats any isolated member that accumulated longer uncommitted logs from term 1.

Because every acknowledged record resides on a majority and every winning candidate collects votes from a majority, quorum intersection guarantees that at least one voter holds the acknowledged record. That voter refuses any candidate with a less-fresh log, automating the longest-log promotion rule that an operator executed manually in Chapter 3.

Ascending to Leadership and Stepping Down

Upon collecting a majority of votes, Member::lead (Listing 4.11) initializes every peer’s next guess to self.last_sequence(), appends the new term’s in-band marker to the WAL, and immediately broadcasts initial Append RPCs to assert authority and commit the marker.

impl Member {
    /// Becomes the leader of the current term. The first record of the term
    /// is its marker. When a majority has stored the marker, every earlier
    /// record is committed with it.
    fn lead(&mut self) -> io::Result<Vec<Outgoing>> {
        self.role = Role::Leader;
        self.leader = Some(self.id);

        let next = self.last_sequence();
        self.progress = self
            .peers
            .iter()
            .map(|&peer| {
                (
                    peer,
                    Progress {
                        next,
                        matched: 0,
                        heard: self.now,
                    },
                )
            })
            .collect();

        self.records.push(record);
        self.terms.push(self.term);

        Ok(self.replicate())
    }
}

4.5 Log Matching and Conflicting-Tail Repair

In Chapter 3, a returning former leader had to wipe its disk because uncommitted records at the end of its log could conflict with records written by a new leader at the same sequence indices. Raft resolves divergent tails automatically via the Log Matching Property (Figure 4-5): if two logs contain an entry with the same (index, term), then both logs are guaranteed identical across every preceding index 1 through index.

A follower validates every incoming Append against three sequential checks (Figure 4-6):

  1. Is msg.term >= self.term? If not, refuse and report self.term.
  2. Does the follower hold a record at msg.previous_sequence? If not, refuse and report self.last_sequence().
  3. Does the follower’s record at msg.previous_sequence have term equal to msg.previous_term? If not, refuse and report msg.previous_sequence - 1 so the leader steps backward by one index until reaching the highest matching prefix.

Listing 4.13 implements Member::on_append, resetting the election timer upon accepting the current leader’s term and invoking store plus apply_committed once all three checks pass.

Listing 4.13 Three-check Append validation in raft/src/lib.rs. raft/src/lib.rs

impl Member {
    fn on_append(&mut self, request: AppendRequest) -> io::Result<AppendAnswer> {
        let refuse = |member: &Member, last_sequence| AppendAnswer {
            term: member.term,
            from: member.id,
            appended: false,
            last_sequence,
        };

        if request.term < self.term {
            return Ok(refuse(self, self.last_sequence()));
        }

        // A message of the current term or a newer one comes from the leader.
        self.step_down(request.term)?;
        self.leader = Some(request.leader);
        self.quiet_since = self.now;

        if request.previous_sequence > self.last_sequence() {
            return Ok(refuse(self, self.last_sequence()));
        }

        if self.term_at(request.previous_sequence) != request.previous_term {
            return Ok(refuse(self, request.previous_sequence - 1));
        }

        let matched = request.previous_sequence + request.records.len() as u64;
        self.store(
            request.previous_sequence,
            request.previous_term,
            request.records,
        )?;
        self.commit(
            request
                .committed_sequence
                .min(matched),
        );

        Ok(AppendAnswer {
            term: self.term,
            from: self.id,
            appended: true,
            last_sequence: matched,
        })
    }
}

impl Member {
    /// Makes the log equal to the leader's from `previous` onward: records
    /// the member already has are skipped, a record that differs is removed
    /// together with everything after it, and the rest is appended.
    fn store(&mut self, previous: u64, previous_term: u64, records: Vec<Record>) -> io::Result<()> {
        let terms = terms_of(&records, previous_term);
        let mut fresh = 0;

        for (index, record) in records.iter().enumerate() {
            let sequence = previous + index as u64 + 1;

            if sequence > self.last_sequence() {
                break;
            }

            if self.term_at(sequence) != terms[index]
                || &self.records[sequence as usize - 1] != record
            {
                self.truncate(sequence - 1)?;

                break;
            }

            fresh = index + 1;
        }

        if fresh < records.len() {
            self.log
                .append_records(&records[fresh..])?;
            self.records
                .extend_from_slice(&records[fresh..]);
            self.terms
                .extend_from_slice(&terms[fresh..]);
        }

        Ok(())
    }
}

4.6 Current-Term Commit Rule and Pure Event Loop

Listing 4.19 implements apply_committed and advance. Unlike Chapter 3’s single-term majority_sequence, Raft’s advance commits index candidate by replica counting only if self.term_of(candidate) == self.term.

Listing 4.19 Current-term commit rule and state-machine application in raft/src/lib.rs. raft/src/lib.rs

impl Member {
    /// Applies the records up to `sequence` that are not applied yet. Term
    /// markers are records of the log and are not entries.
    fn commit(&mut self, sequence: u64) {
        let until = sequence.min(self.last_sequence());

        // A record that marks the start of a term changes no key.
        let changes: Vec<Record> = (self.committed..until)
            .map(|index| self.records[index as usize].clone())
            .filter(|record| marked_term(record).is_none())
            .collect();

        for record in changes {
            apply(&mut self.entries, record);
        }

        self.committed = self.committed.max(until);
    }

    /// The leader's commit rule. A record of an earlier term is not counted
    /// on its own: it becomes committed together with the first record of
    /// the leader's own term that a majority has stored.
    fn advance(&mut self) {
        let mut stored: Vec<u64> = self
            .progress
            .values()
            .map(|progress| progress.matched)
            .collect();
        stored.push(self.last_sequence());
        stored.sort_unstable_by(|a, b| b.cmp(a));

        let on_majority = stored[self.majority() - 1];

        if on_majority > self.committed && self.term_at(on_majority) == self.term {
            self.commit(on_majority);
        }
    }
}

Restricting direct replica-count commits to entries of the current term closes a subtle Raft safety hazard (Figure 8 of the Raft paper): an entry written in an earlier term can be replicated to a majority yet still be overwritten by a future leader elected by a disjoint quorum of peers carrying an intermediate term, until a record from the current term reaches a majority. Once a current-term record reaches a majority, the Log Matching Property locks in all preceding entries indirectly. Here the term marker performs its second role: appending and committing the term marker immediately upon election commits every inherited prior-term entry without waiting for a client write to arrive.

Because raft owns neither clocks nor sockets, callers drive it through three pure entry points: tick (Listing 4.20) advances heartbeat or election timers; handle (Listing 4.21) dispatches incoming peer messages and returns outbound Envelope batches; and client methods (Listing 4.22) enforce can_read (requiring leadership, committed term marker so inherited state is applied, and majority heartbeat contact within the past 10 ticks) and propose.

impl Member {
    /// Whether this member is the leader and every record of its log is
    /// committed, so that it can accept a write.
    pub fn is_settled(&self) -> bool {
        self.role == Role::Leader && self.committed == self.last_sequence()
    }

    /// Checks the condition of a write and appends its record to the log.
    /// The caller sends the messages of `replicate` afterwards.
    pub fn propose(&mut self, change: Change, condition: Condition) -> Result<u64, StoreError> {
        let key = match &change {
            Change::Put { key, .. } | Change::Delete { key } => key,
        };
        let current = self
            .entries
            .get(key)
            .map(|entry| entry.version);

        if matches!(change, Change::Delete { .. }) && current.is_none() {
            return Err(StoreError::NotFound);
        }

        check(condition, current)?;

        let record = self.log.append(change)?;
        let sequence = record.sequence;
        self.records.push(record);
        self.terms.push(self.term);

        Ok(sequence)
    }

    /// Whether this member may answer a read: it is the leader, the marker
    /// of its term is committed, and a majority of the members, itself
    /// included, has answered within the last 10 ticks.
    pub fn can_read(&self) -> bool {
        let recent = self
            .progress
            .values()
            .filter(|progress| self.now - progress.heard < 10)
            .count();

        self.role == Role::Leader
            && self.term_at(self.committed) == self.term
            && recent + 1 >= self.majority()
    }

    pub fn get(&self, key: &str) -> Option<&Entry> {
        self.entries.get(key)
    }
}

    fn open(root: &Path) -> Result<Cluster, Box<dyn Error>> {

            .copied()

            self.discarded += member.discarded();
        }
    }

            self.network.extend(member.tick()?);
        }

    }

    /// down is lost.

        let Outgoing { to, message } = self.network.remove(index);

        if let Some(member) = self.up.get_mut(&to) {
            self.network
                .extend(member.handle(message)?);
        }

        self.check()
    }

    /// Delivers one of the messages that are on their way, chosen at random.
    fn deliver_any(&mut self, random: &mut Random) -> Result<(), Box<dyn Error>> {
        if self.network.is_empty() {
            return Ok(());
        }

        self.deliver(random.below(self.network.len()))
    }

    /// Loses one of the messages that are on their way.
    fn lose_any(&mut self, random: &mut Random) {
        if !self.network.is_empty() {
            self.network
                .remove(random.below(self.network.len()));
        }
    }

    /// Starts a member that is down.
    fn restart(&mut self, id: NodeId) -> Result<(), Box<dyn Error>> {
        if self.up.contains_key(&id) {
            return Ok(());
        }

        self.start(id)
    }

    /// Delivers messages until none is on its way.
    fn deliver_all(&mut self) -> Result<(), Box<dyn Error>> {
        while !self.network.is_empty() {
            self.deliver(0)?;
        }

        Ok(())
    }

    /// Sends a write to a leader that can accept one, if there is one.
    fn write(&mut self) -> Result<bool, Box<dyn Error>> {
        let Some(leader) = self
            .up
            .values_mut()

            .values()
            .filter(|member| member.role() == Role::Leader)

impl Cluster {
    /// The properties that must hold after every step.
    fn check(&mut self) -> Result<(), Box<dyn Error>> {
        // No 2 members lead the same term.
        for member in self
            .up
            .values()
            .filter(|member| member.role() == Role::Leader)
        {
            let first = *self
                .leaders
                .entry(member.term())
                .or_insert(member.id());

            if first != member.id() {
                return Err(format!(
                    "members {first} and {} both lead term {}",
                    member.id(),
                    member.term()
                )
                .into());
            }
        }

        // A write is acknowledged when the leader that accepted it, still
        // leading the same term, has committed its record.
        let up = &self.up;
        let committed = |write: &Pending| {
            up.get(&write.leader)
                .is_some_and(|leader| {
                    leader.role() == Role::Leader
                        && leader.term() == write.term
                        && leader.committed() >= write.sequence
                })
        };
        let (done, waiting): (Vec<Pending>, Vec<Pending>) = self
            .pending
            .drain(..)
            .partition(committed);

        self.acknowledged.extend(
            done.into_iter()
                .map(|write| (write.sequence, write.key)),
        );
        self.pending = waiting;

        // Every member that has committed the sequence of an acknowledged
        // write holds that write at that sequence.
        for (sequence, key) in &self.acknowledged {
            for member in self
                .up
                .values()
                .filter(|member| member.committed() >= *sequence)
            {
                let holds = matches!(&member.records()[*sequence as usize - 1].change, Change::Put { key: held, .. } if held == key);

                if !holds {
                    return Err(format!(
                        "member {} lost the acknowledged write of {key}",
                        member.id()
                    )
                    .into());
                }
            }
        }

        Ok(())
    }

/// Ends the faults: every member runs and every message arrives. The
/// members must then agree on a leader and on a log that holds every
/// acknowledged write.
fn recover(cluster: &mut Cluster) -> Result<(), Box<dyn Error>> {
    for id in MEMBERS {
        if !cluster.up.contains_key(&id) {
            cluster.start(id)?;
        }
    }

    let agreed = |cluster: &Cluster| {
        cluster
            .leader()
            .is_some_and(|leader| {
                leader.is_settled()
                    && cluster
                        .up
                        .values()
                        .all(|member| member.records() == leader.records())
            })
    };

    for _ in 0..200 {
        if agreed(cluster) {
            break;
        }

        for id in MEMBERS {
            cluster.tick(id)?;
        }

        cluster.deliver_all()?;
    }

    if !agreed(cluster) {
        return Err("the members did not agree after the faults ended".into());
    }

    let leader = cluster
        .leader()
        .ok_or("the members have no leader after the faults ended")?;

    for (sequence, key) in &cluster.acknowledged {
        if leader
            .get(key)
            .is_none_or(|entry| entry.version != *sequence)

            return Err(
                format!("the acknowledged write of {key} is missing after recovery").into(),

    Ok(())

impl Node {
    /// Sends each message in a task of its own, so that a member that does
    /// not answer delays nothing else.
    fn dispatch(self: &Arc<Node>, messages: Vec<Outgoing>) {
        for message in messages {
            tokio::spawn(Arc::clone(self).send(message));
        }
    }

    /// Carries one request to a member and gives the answer to this member.
    async fn send(self: Arc<Node>, outgoing: Outgoing) {
        let Some(channel) = self
            .peers
            .get(&outgoing.to)
            .cloned()
        else {
            return;
        };

        let answer = match outgoing.message {
            Message::Append(request) => {
                let call = async move {
                    ReplicationClient::new(channel)
                        .append(proto::AppendRequest::from(request))
                        .await
                };

                timeout(ANSWER, call)
                    .await
                    .ok()
                    .and_then(Result::ok)
                    .map(|answer| appended(outgoing.to, answer.into_inner()))
            }
            Message::Vote(request) => {
                let call = async move {
                    ElectionClient::new(channel)
                        .request_vote(proto::VoteRequest::from(request))
                        .await
                };

                timeout(ANSWER, call)
                    .await
                    .ok()
                    .and_then(Result::ok)
                    .map(|answer| voted(outgoing.to, answer.into_inner()))
            }
            // An answer travels as the response of the call that asked.
            Message::Appended(..) | Message::Voted(..) => None,
        };

        if let Some(answer) = answer {
            self.deliver(answer);
        }
    }

    /// Gives the member a message and sends what the member returns.
    fn deliver(self: &Arc<Node>, message: Message) {
        match self.with_member(|member| member.handle(message)) {
            Ok(messages) => self.dispatch(messages),
            Err(error) => eprintln!("the member could not process a message: {error}"),
        }
    }
}

impl Node {
    fn not_leader(member: &Member) -> ApiError {
        match member.leader() {
            Some(leader) => ApiError::Misdirected(format!("the leader is member {leader}")),
            None => ApiError::NoLeader,
        }
    }

    /// A write on the leader. It is acknowledged when its record is
    /// committed and this member has led the same term throughout.
    pub async fn write(
        self: &Arc<Node>,
        change: Change,
        condition: Condition,
    ) -> Result<Written, ApiError> {
        let turn = self.turn.lock().await;

        let last = {
            let member = self.member.lock();

            if member.role() != Role::Leader {
                return Err(Node::not_leader(&member));
            }

            member.last_sequence()
        };

        self.wait_for(last).await?;

        let (written, term, messages) = self.with_member(|member| {
            if !member.is_settled() {
                return Err(Node::not_leader(member));
            }

            let created = match &change {
                Change::Put { key, .. } | Change::Delete { key } => member.get(key).is_none(),
            };
            let version = member.propose(change, condition)?;

            Ok((
                Written { version, created },
                member.term(),
                member.replicate(),
            ))
        })?;

        self.dispatch(messages);
        self.wait_for(written.version)
            .await?;
        drop(turn);

        // A member that lost the leadership while it waited may hold another
        // leader's record at this sequence.
        let member = self.member.lock();

        if member.role() == Role::Leader && member.term() == term {
            Ok(written)
        } else {
            Err(ApiError::Unavailable(
                "the leadership changed before the record was committed".into(),
            ))
        }
    }

    async fn wait_for(&self, sequence: u64) -> Result<(), ApiError> {
        let mut committed = self.committed.subscribe();

        let reached = committed.wait_for(|&committed| committed >= sequence);
        let in_time = timeout(COMMIT, reached)
            .await
            .is_ok_and(|reached| reached.is_ok());

        if in_time {
            Ok(())
        } else {
            Err(ApiError::Unavailable(format!(
                "record {sequence} is not on a majority of the members"
            )))
        }
    }

    pub fn get(&self, key: &str) -> Result<Entry, ApiError> {
        let member = self.member.lock();

        if member.role() != Role::Leader {
            return Err(Node::not_leader(&member));
        }

        if !member.can_read() {
            return Err(ApiError::Unavailable(
                "this leader cannot confirm that it still leads".into(),
            ));
        }

        member
            .get(key)
            .cloned()
            .ok_or(ApiError::NotFound)
    }
}

//! A member of a shard that elects its own leader.
//!
//! A `Member` is a replica with a role. It follows the Raft algorithm: a
//! follower that hears nothing from a leader stands for election, a
//! candidate that receives the votes of a majority becomes the leader, and
//! a leader replicates its log. The type does no I/O on the network and
//! reads no clock. The caller delivers messages to `handle`, calls `tick`
//! at a fixed interval, and sends the messages that both return.

use std::collections::BTreeMap;
use std::fs::{self, File};
use std::io::{self, Write};
use std::path::{Path, PathBuf};

use kv::{Change, Condition, Entry, Log, Record, StoreError, apply, check};

pub type NodeId = u32;

/// Sent by a leader to a follower.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AppendRequest {
    pub term: u64,
    pub leader: NodeId,
    /// The sequence of the record that precedes `records`, and its term.
    pub previous_sequence: u64,
    pub previous_term: u64,
    pub records: Vec<Record>,
    pub committed_sequence: u64,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct AppendAnswer {
    pub term: u64,
    pub from: NodeId,
    pub appended: bool,
    /// When appended: the last sequence that is known to match the leader's
    /// log. When refused: the sequence the leader should continue from.
    pub last_sequence: u64,
}

/// Sent by a candidate to every other member.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct VoteRequest {
    pub term: u64,
    pub candidate: NodeId,

pub struct VoteAnswer {
    pub term: u64,

    Voted(VoteAnswer),

/// A message and the member it is addressed to.

/// The ticks a follower waits for a leader before it stands for election:
/// 10 to 19, different for each member and each term, so that 2 members
/// seldom stand at the same moment. A tick is 100 ms in the node.
fn election_timeout(id: NodeId, term: u64) -> u64 {
    10 + (u64::from(id) * 7 + term * 3) % 10
}

/// What the leader knows about one follower.
#[derive(Debug, Clone, Copy, Default)]
struct Progress {
    /// The sequence after which the next message to the follower begins.
    next: u64,
    /// The last sequence the follower has confirmed to match.
    matched: u64,
    /// The tick at which the follower last answered.
    heard: u64,
}

pub struct Member {
    id: NodeId,
    peers: Vec<NodeId>,
    directory: PathBuf,
    sync: bool,

    log: Log,
    /// Every record of the log. Record `n` is at index `n - 1`.
    records: Vec<Record>,
    /// The term in which each record was written.
    terms: Vec<u64>,
    entries: BTreeMap<String, Entry>,
    committed: u64,

    /// The current term, and the member this one voted for in it. Both are
    /// stored on disk before any answer that depends on them is sent.
    term: u64,
    voted_for: Option<NodeId>,

    role: Role,
    /// The leader of the current term, when this member knows it.
    leader: Option<NodeId>,
    votes: usize,
    progress: BTreeMap<NodeId, Progress>,
    /// Ticks since the member started, and the tick of the last message
    /// from a leader or the last vote granted.
    now: u64,
    quiet_since: u64,
    /// The records this member has removed from its log because they
    /// differed from a leader's.
    discarded: u64,
}

/// The key of a term marker. A client cannot write the empty key, so the
/// log can use it for a record of its own: the first record a new leader
/// appends, whose value is the leader's term.
const MARKER: &str = "";

fn marker(term: u64) -> Change {
    Change::Put {
        key: MARKER.to_owned(),
        value: term.to_le_bytes().to_vec(),
    }
}

/// The term a record starts, if it is a term marker.
fn marked_term(record: &Record) -> Option<u64> {
    let Change::Put { key, value } = &record.change else {
        return None;
    };

    if key != MARKER {
        return None;
    }

    let term: [u8; 8] = value.as_slice().try_into().ok()?;

    Some(u64::from_le_bytes(term))
}

/// The term of each record: the term of the last marker at or before it.
fn terms_of(records: &[Record], mut term: u64) -> Vec<u64> {
    let mut terms = Vec::with_capacity(records.len());

    for record in records {
        term = marked_term(record).unwrap_or(term);
        terms.push(term);
    }

    terms
}

impl Member {
    /// Opens the member in `directory`. It starts as a follower, with
    /// nothing applied, in the term it had reached before it stopped.
    pub fn open(
        directory: &Path,
        id: NodeId,
        peers: Vec<NodeId>,
        sync: bool,

        let (log, recovery) = Log::open(directory, sync)?;

        Ok(Member {
            id,
            peers,
            directory: directory.to_owned(),
            sync,
            log,
            records: recovery.records,
            terms,
            entries: BTreeMap::new(),
            committed: 0,

            role: Role::Follower,
            leader: None,
            votes: 0,
            progress: BTreeMap::new(),
            now: 0,
            quiet_since: 0,
            discarded: 0,
        })
    }

        self.id
    }

    pub fn role(&self) -> Role {
        self.role
    }

    pub fn term(&self) -> u64 {
        self.term
    }

        self.leader
    }

        self.records.len() as u64
    }

    pub fn committed(&self) -> u64 {
        self.committed
    }

        &self.records
    }

    pub fn discarded(&self) -> u64 {
        self.discarded
    }

    fn last_term(&self) -> u64 {
        self.terms
            .last()
            .copied()
            .unwrap_or(0)
    }

    /// The term of record `sequence`, or 0 for the position before the log.
    fn term_at(&self, sequence: u64) -> u64 {
        if sequence == 0 {
            0
        } else {

        }
    }

        let members = self.peers.len() + 1;

    }

const STATE_FILE: &str = "state";

/// Reads the term and the vote. A member that has no state file has not
/// voted and is in term 0.
fn read_state(directory: &Path) -> io::Result<(u64, Option<NodeId>)> {
    let text = match fs::read_to_string(directory.join(STATE_FILE)) {
        Ok(text) => text,
        Err(error) if error.kind() == io::ErrorKind::NotFound => return Ok((0, None)),
        Err(error) => return Err(error),
    };

    let mut fields = text
        .split_whitespace()
        .map(str::parse::<u64>);
    let invalid = || io::Error::new(io::ErrorKind::InvalidData, "the state file is malformed");
    let term = fields
        .next()
        .and_then(Result::ok)
        .ok_or_else(invalid)?;
    let voted_for = fields
        .next()
        .and_then(Result::ok)
        .map(|id| id as NodeId);

    Ok((term, voted_for))
}

impl Member {
    /// Stores the term and the vote. The new file replaces the old one in a
    /// single step, so a crash leaves one of the 2 and not a mixture.
    fn save_state(&self) -> io::Result<()> {
        let temporary = self.directory.join("state.new");
        let vote = self
            .voted_for
            .map_or(String::new(), |id| id.to_string());
        let mut file = File::create(&temporary)?;

        file.write_all(format!("{} {vote}\n", self.term).as_bytes())?;

        if self.sync {
            file.sync_all()?;
        }

        fs::rename(&temporary, self.directory.join(STATE_FILE))?;

        if self.sync {
            File::open(&self.directory)?.sync_all()?;
        }

        Ok(())
    }
}

impl Member {
    /// Applies the records up to `sequence` that are not applied yet. Term
    /// markers are records of the log and are not entries.
    fn commit(&mut self, sequence: u64) {
        let until = sequence.min(self.last_sequence());

        // A record that marks the start of a term changes no key.
        let changes: Vec<Record> = (self.committed..until)
            .map(|index| self.records[index as usize].clone())
            .filter(|record| marked_term(record).is_none())
            .collect();

        for record in changes {
            apply(&mut self.entries, record);
        }

        self.committed = self.committed.max(until);
    }

    /// The leader's commit rule. A record of an earlier term is not counted
    /// on its own: it becomes committed together with the first record of
    /// the leader's own term that a majority has stored.
    fn advance(&mut self) {
        let mut stored: Vec<u64> = self
            .progress
            .values()
            .map(|progress| progress.matched)
            .collect();
        stored.push(self.last_sequence());
        stored.sort_unstable_by(|a, b| b.cmp(a));

        let on_majority = stored[self.majority() - 1];

        if on_majority > self.committed && self.term_at(on_majority) == self.term {
            self.commit(on_majority);
        }
    }
}

impl Member {
    /// Moves to a newer term as a follower. The vote of the old term does
    /// not carry over.
    fn step_down(&mut self, term: u64) -> io::Result<()> {
        if term > self.term {
            self.term = term;
            self.voted_for = None;
            self.save_state()?;
        }

        self.role = Role::Follower;
        self.leader = None;
        self.progress.clear();

        Ok(())
    }
}

impl Member {
    /// Stands for election in the next term.
    fn stand(&mut self) -> io::Result<Vec<Outgoing>> {
        self.term += 1;
        self.voted_for = Some(self.id);
        self.save_state()?;

        self.role = Role::Candidate;
        self.leader = None;
        self.votes = 1;
        self.quiet_since = self.now;

        let request = VoteRequest {
            term: self.term,
            candidate: self.id,
            last_sequence: self.last_sequence(),
            last_term: self.last_term(),
        };

        Ok(self
            .peers
            .iter()
            .map(|&to| Outgoing {
                to,
                message: Message::Vote(request),
            })
            .collect())
    }
}

impl Member {
    /// Becomes the leader of the current term. The first record of the term
    /// is its marker. When a majority has stored the marker, every earlier
    /// record is committed with it.
    fn lead(&mut self) -> io::Result<Vec<Outgoing>> {
        self.role = Role::Leader;
        self.leader = Some(self.id);

        let next = self.last_sequence();
        self.progress = self
            .peers
            .iter()
            .map(|&peer| {
                (
                    peer,
                    Progress {
                        next,
                        matched: 0,
                        heard: self.now,
                    },
                )
            })
            .collect();

        let record = self.log.append(marker(self.term))?;
        self.records.push(record);
        self.terms.push(self.term);

        Ok(self.replicate())
    }
}

impl Member {
    /// Advances the member's clock by one tick. A leader sends every
    /// follower a message. A follower or a candidate that has waited for
    /// its election timeout stands for election.
    pub fn tick(&mut self) -> io::Result<Vec<Outgoing>> {
        self.now += 1;

        if self.role == Role::Leader {
            return Ok(self.replicate());
        }

        if self.now - self.quiet_since >= election_timeout(self.id, self.term) {
            return self.stand();
        }

        Ok(Vec::new())
    }

    /// A message for every follower: the records it lacks, or a heartbeat.
    pub fn replicate(&self) -> Vec<Outgoing> {
        self.peers
            .iter()
            .filter_map(|&peer| self.append_for(peer))
            .collect()
    }

    fn append_for(&self, peer: NodeId) -> Option<Outgoing> {
        let from = self
            .progress
            .get(&peer)?
            .next
            .min(self.last_sequence());

        let request = AppendRequest {
            term: self.term,
            leader: self.id,
            previous_sequence: from,
            previous_term: self.term_at(from),
            records: self.records[from as usize..].to_vec(),
            committed_sequence: self.committed,
        };

        Some(Outgoing {
            to: peer,
            message: Message::Append(request),
        })
    }
}

impl Member {
    /// Processes a message and returns the messages to send in response.
    pub fn handle(&mut self, message: Message) -> io::Result<Vec<Outgoing>> {
        match message {
            Message::Append(request) => {
                let to = request.leader;
                let answer = self.on_append(request)?;

                Ok(vec![Outgoing {
                    to,
                    message: Message::Appended(answer),
                }])
            }
            Message::Vote(request) => {
                let to = request.candidate;
                let answer = self.on_vote(request)?;

                Ok(vec![Outgoing {
                    to,
                    message: Message::Voted(answer),
                }])
            }
            Message::Appended(answer) => self.on_appended(answer),
            Message::Voted(answer) => self.on_voted(answer),
        }
    }
}

impl Member {
    /// A member grants its vote once in a term, and only to a candidate
    /// whose log is at least as complete as its own.
    fn on_vote(&mut self, request: VoteRequest) -> io::Result<VoteAnswer> {
        if request.term > self.term {
            self.step_down(request.term)?;
        }

        let complete =
            (request.last_term, request.last_sequence) >= (self.last_term(), self.last_sequence());
        let free = self
            .voted_for
            .is_none_or(|id| id == request.candidate);
        let granted = request.term == self.term && complete && free;

        if granted {
            self.voted_for = Some(request.candidate);
            self.save_state()?;
            self.quiet_since = self.now;
        }

        Ok(VoteAnswer {
            term: self.term,
            from: self.id,
            granted,
        })
    }

    fn on_voted(&mut self, answer: VoteAnswer) -> io::Result<Vec<Outgoing>> {
        if answer.term > self.term {
            self.step_down(answer.term)?;

            return Ok(Vec::new());
        }

        if self.role != Role::Candidate || answer.term != self.term || !answer.granted {
            return Ok(Vec::new());
        }

        self.votes += 1;

        if self.votes >= self.majority() {
            self.lead()
        } else {
            Ok(Vec::new())
        }
    }
}

impl Member {
    fn on_append(&mut self, request: AppendRequest) -> io::Result<AppendAnswer> {
        let refuse = |member: &Member, last_sequence| AppendAnswer {
            term: member.term,
            from: member.id,
            appended: false,
            last_sequence,
        };

        if request.term < self.term {
            return Ok(refuse(self, self.last_sequence()));
        }

        // A message of the current term or a newer one comes from the leader.
        self.step_down(request.term)?;
        self.leader = Some(request.leader);
        self.quiet_since = self.now;

        if request.previous_sequence > self.last_sequence() {
            return Ok(refuse(self, self.last_sequence()));
        }

        if self.term_at(request.previous_sequence) != request.previous_term {
            return Ok(refuse(self, request.previous_sequence - 1));
        }

        let matched = request.previous_sequence + request.records.len() as u64;
        self.store(
            request.previous_sequence,
            request.previous_term,
            request.records,
        )?;
        self.commit(
            request
                .committed_sequence
                .min(matched),
        );

        Ok(AppendAnswer {
            term: self.term,
            from: self.id,
            appended: true,
            last_sequence: matched,
        })
    }
}

impl Member {
    /// Makes the log equal to the leader's from `previous` onward: records
    /// the member already has are skipped, a record that differs is removed
    /// together with everything after it, and the rest is appended.
    fn store(&mut self, previous: u64, previous_term: u64, records: Vec<Record>) -> io::Result<()> {
        let terms = terms_of(&records, previous_term);
        let mut fresh = 0;

        for (index, record) in records.iter().enumerate() {
            let sequence = previous + index as u64 + 1;

            if sequence > self.last_sequence() {
                break;
            }

            if self.term_at(sequence) != terms[index]
                || &self.records[sequence as usize - 1] != record
            {
                self.truncate(sequence - 1)?;

                break;
            }

            fresh = index + 1;
        }

        if fresh < records.len() {
            self.log
                .append_records(&records[fresh..])?;
            self.records
                .extend_from_slice(&records[fresh..]);
            self.terms
                .extend_from_slice(&terms[fresh..]);
        }

        Ok(())
    }
}

impl Member {
    /// Removes the records after `keep`. Only records that are not
    /// committed can differ from the leader's, so none of them is applied.
    fn truncate(&mut self, keep: u64) -> io::Result<()> {
        if keep < self.committed {
            return Err(io::Error::other(format!(
                "record {} is committed and differs from the leader's",
                keep + 1
            )));
        }

        let length: usize = self.records[..keep as usize]
            .iter()
            .map(|record| record.encode().len())
            .sum();

        self.discarded += self.last_sequence() - keep;
        self.log
            .truncate(keep, length as u64)?;
        self.records.truncate(keep as usize);
        self.terms.truncate(keep as usize);

        Ok(())
    }
}

impl Member {
    fn on_appended(&mut self, answer: AppendAnswer) -> io::Result<Vec<Outgoing>> {
        if answer.term > self.term {
            self.step_down(answer.term)?;

            return Ok(Vec::new());
        }

        if self.role != Role::Leader || answer.term != self.term {
            return Ok(Vec::new());
        }

        let now = self.now;
        let Some(progress) = self.progress.get_mut(&answer.from) else {
            return Ok(Vec::new());
        };

        progress.heard = now;
        progress.next = answer.last_sequence;

        if answer.appended {
            progress.matched = progress
                .matched
                .max(answer.last_sequence);
        }

        let behind = !answer.appended || answer.last_sequence < self.last_sequence();
        self.advance();

        Ok(if behind {
            self.append_for(answer.from)
                .into_iter()
                .collect()
        } else {
            Vec::new()
        })
    }
}

impl Member {
    /// Whether this member is the leader and every record of its log is
    /// committed, so that it can accept a write.
    pub fn is_settled(&self) -> bool {
        self.role == Role::Leader && self.committed == self.last_sequence()
    }

    /// Checks the condition of a write and appends its record to the log.
    /// The caller sends the messages of `replicate` afterwards.
    pub fn propose(&mut self, change: Change, condition: Condition) -> Result<u64, StoreError> {
        let key = match &change {
            Change::Put { key, .. } | Change::Delete { key } => key,
        };
        let current = self
            .entries
            .get(key)
            .map(|entry| entry.version);

        if matches!(change, Change::Delete { .. }) && current.is_none() {
            return Err(StoreError::NotFound);
        }

        check(condition, current)?;

        let record = self.log.append(change)?;
        let sequence = record.sequence;
        self.records.push(record);
        self.terms.push(self.term);

        Ok(sequence)
    }

    /// Whether this member may answer a read: it is the leader, the marker
    /// of its term is committed, and a majority of the members, itself
    /// included, has answered within the last 10 ticks.
    pub fn can_read(&self) -> bool {
        let recent = self
            .progress
            .values()
            .filter(|progress| self.now - progress.heard < 10)
            .count();

        self.role == Role::Leader
            && self.term_at(self.committed) == self.term
            && recent + 1 >= self.majority()
    }

    pub fn get(&self, key: &str) -> Option<&Entry> {
        self.entries.get(key)
    }
}

//! Command raftsim runs 3 members in one process and decides itself when
//! each clock ticks, which message arrives, which is lost, and which member
//! crashes. It first walks through an election and the repair of a log,
//! and then makes 200 runs of 600 random steps, checking after every step
//! that no 2 members lead the same term and that no acknowledged write is
//! missing.
//!
//! Run it from code/ with:
//!
//!     cargo run --release -p raftsim

use std::collections::BTreeMap;
use std::env;
use std::error::Error;
use std::fs;
use std::path::{Path, PathBuf};
use std::process;

use kv::{Change, Condition};
use raft::{Member, NodeId, Outgoing, Role};

/// A generator of pseudo-random numbers. The same seed gives the same
/// numbers, so a run that fails can be repeated exactly.
struct Random(u64);

impl Random {
    fn next(&mut self) -> u64 {
        self.0 ^= self.0 << 13;
        self.0 ^= self.0 >> 7;
        self.0 ^= self.0 << 17;

        self.0
    }

    /// A number below `bound`.
    fn below(&mut self, bound: usize) -> usize {
        (self.next() % bound as u64) as usize
    }
}

const MEMBERS: [NodeId; 3] = [1, 2, 3];

/// A write that a leader has accepted and not yet committed.
struct Pending {
    leader: NodeId,
    term: u64,
    sequence: u64,
    key: String,
}

struct Cluster {
    root: PathBuf,
    /// The members that are running. A crashed member is absent.
    up: BTreeMap<NodeId, Member>,
    /// The messages that are on their way.
    network: Vec<Outgoing>,
    pending: Vec<Pending>,
    /// The sequence and the key of every acknowledged write.
    acknowledged: Vec<(u64, String)>,
    /// The leader that was seen in each term.
    leaders: BTreeMap<u64, NodeId>,
    discarded: u64,
    writes: u64,
}

impl Cluster {
    fn open(root: &Path) -> Result<Cluster, Box<dyn Error>> {
        let mut cluster = Cluster {
            root: root.to_owned(),
            up: BTreeMap::new(),
            network: Vec::new(),
            pending: Vec::new(),
            acknowledged: Vec::new(),
            leaders: BTreeMap::new(),
            discarded: 0,
            writes: 0,
        };

        for id in MEMBERS {
            cluster.start(id)?;
        }

        Ok(cluster)
    }

    fn start(&mut self, id: NodeId) -> Result<(), Box<dyn Error>> {
        let peers = MEMBERS
            .iter()
            .copied()
            .filter(|&peer| peer != id)
            .collect();
        let member = Member::open(
            &self
                .root
                .join(format!("member-{id}")),
            id,
            peers,
            false,
        )?;
        self.up.insert(id, member);

        Ok(())
    }

    /// Stops a member. Its files remain, and its memory is lost.
    fn crash(&mut self, id: NodeId) {
        if let Some(member) = self.up.remove(&id) {
            self.discarded += member.discarded();
        }
    }

    fn tick(&mut self, id: NodeId) -> Result<(), Box<dyn Error>> {
        if let Some(member) = self.up.get_mut(&id) {
            self.network.extend(member.tick()?);
        }

        self.check()
    }

    /// Delivers the message at `index`. A message for a member that is
    /// down is lost.
    fn deliver(&mut self, index: usize) -> Result<(), Box<dyn Error>> {
        let Outgoing { to, message } = self.network.remove(index);

        if let Some(member) = self.up.get_mut(&to) {
            self.network
                .extend(member.handle(message)?);
        }

        self.check()
    }

    /// Delivers one of the messages that are on their way, chosen at random.
    fn deliver_any(&mut self, random: &mut Random) -> Result<(), Box<dyn Error>> {
        if self.network.is_empty() {
            return Ok(());
        }

        self.deliver(random.below(self.network.len()))
    }

    /// Loses one of the messages that are on their way.
    fn lose_any(&mut self, random: &mut Random) {
        if !self.network.is_empty() {
            self.network
                .remove(random.below(self.network.len()));
        }
    }

    /// Starts a member that is down.
    fn restart(&mut self, id: NodeId) -> Result<(), Box<dyn Error>> {
        if self.up.contains_key(&id) {
            return Ok(());
        }

        self.start(id)
    }

    /// Delivers messages until none is on its way.
    fn deliver_all(&mut self) -> Result<(), Box<dyn Error>> {
        while !self.network.is_empty() {
            self.deliver(0)?;
        }

        Ok(())
    }

    /// Sends a write to a leader that can accept one, if there is one.
    fn write(&mut self) -> Result<bool, Box<dyn Error>> {
        let Some(leader) = self
            .up
            .values_mut()
            .find(|member| member.is_settled())
        else {
            return Ok(false);
        };

        self.writes += 1;
        let key = format!("key-{}", self.writes);
        let change = Change::Put {
            key: key.clone(),
            value: b"1".to_vec(),
        };
        let sequence = leader.propose(change, Condition::Always)?;

        self.pending.push(Pending {
            leader: leader.id(),
            term: leader.term(),
            sequence,
            key,
        });
        self.network
            .extend(leader.replicate());

        Ok(true)
    }

    fn leader(&self) -> Option<&Member> {
        self.up
            .values()
            .filter(|member| member.role() == Role::Leader)
            .max_by_key(|member| member.term())
    }
}

impl Cluster {
    /// The properties that must hold after every step.
    fn check(&mut self) -> Result<(), Box<dyn Error>> {
        // No 2 members lead the same term.
        for member in self
            .up
            .values()
            .filter(|member| member.role() == Role::Leader)
        {
            let first = *self
                .leaders
                .entry(member.term())
                .or_insert(member.id());

            if first != member.id() {
                return Err(format!(
                    "members {first} and {} both lead term {}",
                    member.id(),
                    member.term()
                )
                .into());
            }
        }

        // A write is acknowledged when the leader that accepted it, still
        // leading the same term, has committed its record.
        let up = &self.up;
        let committed = |write: &Pending| {
            up.get(&write.leader)
                .is_some_and(|leader| {
                    leader.role() == Role::Leader
                        && leader.term() == write.term
                        && leader.committed() >= write.sequence
                })
        };
        let (done, waiting): (Vec<Pending>, Vec<Pending>) = self
            .pending
            .drain(..)
            .partition(committed);

        self.acknowledged.extend(
            done.into_iter()
                .map(|write| (write.sequence, write.key)),
        );
        self.pending = waiting;

        // Every member that has committed the sequence of an acknowledged
        // write holds that write at that sequence.
        for (sequence, key) in &self.acknowledged {
            for member in self
                .up
                .values()
                .filter(|member| member.committed() >= *sequence)
            {
                let holds = matches!(&member.records()[*sequence as usize - 1].change, Change::Put { key: held, .. } if held == key);

                if !holds {
                    return Err(format!(
                        "member {} lost the acknowledged write of {key}",
                        member.id()
                    )
                    .into());
                }
            }
        }

        Ok(())
    }
}

fn show(cluster: &Cluster) -> String {
    let describe = |id: &NodeId| match cluster.up.get(id) {
        Some(member) => format!(
            "{id}: {:?} term {} log {}",
            member.role(),
            member.term(),
            member.last_sequence()
        ),
        None => format!("{id}: down"),
    };

    MEMBERS
        .iter()
        .map(describe)
        .collect::<Vec<_>>()
        .join(" | ")
}

/// Ticks every running member, delivering all messages after each tick,
/// until a member leads. It returns the number of ticks.
fn elect(cluster: &mut Cluster) -> Result<u64, Box<dyn Error>> {
    let mut ticks = 0;

    while cluster
        .up
        .values()
        .all(|member| !member.is_settled())
    {
        ticks += 1;

        for id in MEMBERS {
            cluster.tick(id)?;
        }

        cluster.deliver_all()?;
    }

    Ok(ticks)
}

fn cases(root: &Path) -> Result<(), Box<dyn Error>> {
    let mut cluster = Cluster::open(root)?;

    println!("start:            {}", show(&cluster));

    let ticks = elect(&mut cluster)?;
    println!("after {ticks:2} ticks:   {}", show(&cluster));

    for _ in 0..3 {
        cluster.write()?;
        cluster.deliver_all()?;
    }

    println!(
        "after 3 writes:   {}, {} acknowledged",
        show(&cluster),
        cluster.acknowledged.len()
    );

    // The leader accepts a write and crashes before it sends the record.
    let old = cluster
        .leader()
        .map(Member::id)
        .ok_or("no leader")?;
    cluster.write()?;
    cluster.network.clear();
    cluster.crash(old);
    println!(
        "leader {old} appends record 5 and crashes: {}",
        show(&cluster)
    );

    let ticks = elect(&mut cluster)?;
    println!("after {ticks:2} ticks:   {}", show(&cluster));

    cluster.write()?;
    cluster.deliver_all()?;
    println!(
        "after 1 write:    {}, {} acknowledged",
        show(&cluster),
        cluster.acknowledged.len()
    );

    cluster.start(old)?;
    println!("member {old} returns: {}", show(&cluster));

    for _ in 0..2 {
        for id in MEMBERS {
            cluster.tick(id)?;
        }

        cluster.deliver_all()?;
    }

    let discarded = cluster
        .up
        .get(&old)
        .map_or(0, Member::discarded);
    println!("after 2 ticks:    {}", show(&cluster));
    println!(
        "member {old} discarded {discarded} record that was never committed, and holds the leader's records in its place"
    );

    Ok(())
}

const RUNS: u64 = 200;
const STEPS: usize = 600;

/// One run: random ticks, deliveries, losses, crashes, restarts and writes.
fn run(root: &Path, seed: u64) -> Result<Cluster, Box<dyn Error>> {
    let mut cluster = Cluster::open(root)?;
    let mut random = Random(seed);

    for _ in 0..STEPS {
        let id = MEMBERS[random.below(MEMBERS.len())];

        match random.below(100) {
            0..40 => cluster.tick(id)?,
            40..82 => cluster.deliver_any(&mut random)?,
            82..87 => cluster.lose_any(&mut random),
            87..90 => cluster.crash(id),
            90..94 => cluster.restart(id)?,
            94.. => cluster.write().map(drop)?,
        }
    }

    recover(&mut cluster)?;

    Ok(cluster)
}

/// Ends the faults: every member runs and every message arrives. The
/// members must then agree on a leader and on a log that holds every
/// acknowledged write.
fn recover(cluster: &mut Cluster) -> Result<(), Box<dyn Error>> {
    for id in MEMBERS {
        if !cluster.up.contains_key(&id) {
            cluster.start(id)?;
        }
    }

    let agreed = |cluster: &Cluster| {
        cluster
            .leader()
            .is_some_and(|leader| {
                leader.is_settled()
                    && cluster
                        .up
                        .values()
                        .all(|member| member.records() == leader.records())
            })
    };

    for _ in 0..200 {
        if agreed(cluster) {
            break;
        }

        for id in MEMBERS {
            cluster.tick(id)?;
        }

        cluster.deliver_all()?;
    }

    if !agreed(cluster) {
        return Err("the members did not agree after the faults ended".into());
    }

    let leader = cluster
        .leader()
        .ok_or("the members have no leader after the faults ended")?;

    for (sequence, key) in &cluster.acknowledged {
        if leader
            .get(key)
            .is_none_or(|entry| entry.version != *sequence)
        {
            return Err(
                format!("the acknowledged write of {key} is missing after recovery").into(),
            );
        }
    }

    Ok(())
}

fn runs(root: &Path) -> Result<(), Box<dyn Error>> {
    let (mut leaders, mut acknowledged, mut discarded, mut most_terms) = (0, 0, 0, 0);

    for seed in 1..=RUNS {
        let directory = root.join(format!("run-{seed}"));
        let mut cluster = run(&directory, seed)?;

        for id in MEMBERS {
            cluster.crash(id);
        }

        leaders += cluster.leaders.len();
        acknowledged += cluster.acknowledged.len();
        discarded += cluster.discarded;
        most_terms = most_terms.max(
            cluster
                .leaders
                .keys()
                .next_back()
                .copied()
                .unwrap_or(0),
        );

        fs::remove_dir_all(&directory)?;
    }

    println!("{RUNS} runs of {STEPS} random steps:");
    println!("  {leaders} leaders were elected, and no term had 2 leaders");
    println!("  {acknowledged} writes were acknowledged, and every one was present after recovery");
    println!(
        "  {discarded} uncommitted records were discarded by members whose log differed from a leader's"
    );
    println!("  the highest term reached in a run was {most_terms}");

    Ok(())
}

fn main() -> Result<(), Box<dyn Error>> {
    let root = env::temp_dir().join(format!("raftsim-{}", process::id()));
    let result = cases(&root.join("cases")).and_then(|()| runs(&root));

    fs::remove_dir_all(&root)?;

    result
}

fn record_to_proto(record: &Record) -> proto::Record {
    let change = match record.change.clone() {
        Change::Put { key, value } => proto::record::Change::Put(proto::Put { key, value }),
        Change::Delete { key } => proto::record::Change::Delete(proto::Delete { key }),
    };

    proto::Record {
        sequence: record.sequence,
        change: Some(change),
    }
}

fn record_from_proto(record: proto::Record) -> Result<Record, Status> {
    let change = match record.change {
        Some(proto::record::Change::Put(put)) => Change::Put {
            key: put.key,
            value: put.value,
        },
        Some(proto::record::Change::Delete(delete)) => Change::Delete { key: delete.key },
        None => return Err(Status::invalid_argument("a record without a change")),
    };

    Ok(Record {
        sequence: record.sequence,
        change,
    })
}

        let answer = self
            .node
            .answer(Message::Vote(request))
            .map_err(|error| Status::unavailable(error.to_string()))?;

        let Message::Voted(answer) = answer else {
            return Err(Status::internal(
                "the member answered with another kind of message",
            ));
        };

        Ok(Response::new(proto::VoteResponse {
            term: answer.term,
            granted: answer.granted,
        }))
    }
}

//! A node: a member, its clock, and the connections that carry its
//! messages to the other members.

use std::collections::BTreeMap;
use std::io;
use std::sync::Arc;
use std::time::Duration;

use kv::{Change, Condition, Entry, Written};
use kvd::api::ApiError;
use parking_lot::Mutex;
use raft::{Member, Message, NodeId, Outgoing, Role};
use tokio::sync::watch;
use tokio::task;
use tokio::time::{interval, timeout};
use tonic::transport::{Channel, Endpoint};

use crate::rpc::{ElectionClient, ReplicationClient, appended, proto, voted};

/// The length of a tick of the member's clock.
pub const TICK: Duration = Duration::from_millis(100);

/// How long a member waits for the answer to one message.
const ANSWER: Duration = Duration::from_millis(500);

/// How long a write waits for its record to be committed.
const COMMIT: Duration = Duration::from_secs(1);

pub struct Node {
    pub member: Mutex<Member>,
    /// A connection to each of the other members.
    peers: BTreeMap<NodeId, Channel>,
    /// Held by the write that is in progress.
    turn: tokio::sync::Mutex<()>,
    /// The committed sequence, for writes that wait for it to advance.
    committed: watch::Sender<u64>,
}

impl Node {
    pub fn new(
        member: Member,
        addresses: BTreeMap<NodeId, String>,
    ) -> Result<Arc<Node>, tonic::transport::Error> {
        let mut peers = BTreeMap::new();

        for (id, address) in addresses {
            peers.insert(
                id,
                Endpoint::from_shared(address)?
                    .connect_timeout(ANSWER)
                    .connect_lazy(),
            );
        }

        Ok(Arc::new(Node {
            member: Mutex::new(member),
            peers,
            turn: tokio::sync::Mutex::new(()),
            committed: watch::Sender::new(0),
        }))
    }
}

impl Node {
    /// Runs one operation on the member and publishes the committed
    /// sequence. The member waits for the disk, so the operation runs where
    /// blocking is allowed.
    fn with_member<T>(&self, operation: impl FnOnce(&mut Member) -> T) -> T {
        task::block_in_place(|| {
            let mut member = self.member.lock();
            let result = operation(&mut member);
            self.committed
                .send_replace(member.committed());

            result
        })
    }
}

impl Node {
    /// Sends each message in a task of its own, so that a member that does
    /// not answer delays nothing else.
    fn dispatch(self: &Arc<Node>, messages: Vec<Outgoing>) {
        for message in messages {
            tokio::spawn(Arc::clone(self).send(message));
        }
    }

    /// Carries one request to a member and gives the answer to this member.
    async fn send(self: Arc<Node>, outgoing: Outgoing) {
        let Some(channel) = self
            .peers
            .get(&outgoing.to)
            .cloned()
        else {
            return;
        };

        let answer = match outgoing.message {
            Message::Append(request) => {
                let call = async move {
                    ReplicationClient::new(channel)
                        .append(proto::AppendRequest::from(request))
                        .await
                };

                timeout(ANSWER, call)
                    .await
                    .ok()
                    .and_then(Result::ok)
                    .map(|answer| appended(outgoing.to, answer.into_inner()))
            }
            Message::Vote(request) => {
                let call = async move {
                    ElectionClient::new(channel)
                        .request_vote(proto::VoteRequest::from(request))
                        .await
                };

                timeout(ANSWER, call)
                    .await
                    .ok()
                    .and_then(Result::ok)
                    .map(|answer| voted(outgoing.to, answer.into_inner()))
            }
            // An answer travels as the response of the call that asked.
            Message::Appended(..) | Message::Voted(..) => None,
        };

        if let Some(answer) = answer {
            self.deliver(answer);
        }
    }

    /// Gives the member a message and sends what the member returns.
    fn deliver(self: &Arc<Node>, message: Message) {
        match self.with_member(|member| member.handle(message)) {
            Ok(messages) => self.dispatch(messages),
            Err(error) => eprintln!("the member could not process a message: {error}"),
        }
    }
}

impl Node {
    /// The member's answer to a request that arrived over gRPC.
    pub fn answer(&self, request: Message) -> io::Result<Message> {
        let mut messages = self.with_member(|member| member.handle(request))?;

        messages
            .pop()
            .map(|outgoing| outgoing.message)
            .ok_or_else(|| io::Error::other("the member gave no answer"))
    }

    /// Advances the member's clock, for as long as the node runs.
    pub async fn run_clock(self: Arc<Node>) {
        let mut ticks = interval(TICK);

        loop {
            ticks.tick().await;

            match self.with_member(Member::tick) {
                Ok(messages) => self.dispatch(messages),
                Err(error) => eprintln!("the member could not advance its clock: {error}"),
            }
        }
    }
}

impl Node {
    fn not_leader(member: &Member) -> ApiError {
        match member.leader() {
            Some(leader) => ApiError::Misdirected(format!("the leader is member {leader}")),
            None => ApiError::NoLeader,
        }
    }

    /// A write on the leader. It is acknowledged when its record is
    /// committed and this member has led the same term throughout.
    pub async fn write(
        self: &Arc<Node>,
        change: Change,
        condition: Condition,
    ) -> Result<Written, ApiError> {
        let turn = self.turn.lock().await;

        let last = {
            let member = self.member.lock();

            if member.role() != Role::Leader {
                return Err(Node::not_leader(&member));
            }

            member.last_sequence()
        };

        self.wait_for(last).await?;

        let (written, term, messages) = self.with_member(|member| {
            if !member.is_settled() {
                return Err(Node::not_leader(member));
            }

            let created = match &change {
                Change::Put { key, .. } | Change::Delete { key } => member.get(key).is_none(),
            };
            let version = member.propose(change, condition)?;

            Ok((
                Written { version, created },
                member.term(),
                member.replicate(),
            ))
        })?;

        self.dispatch(messages);
        self.wait_for(written.version)
            .await?;
        drop(turn);

        // A member that lost the leadership while it waited may hold another
        // leader's record at this sequence.
        let member = self.member.lock();

        if member.role() == Role::Leader && member.term() == term {
            Ok(written)
        } else {
            Err(ApiError::Unavailable(
                "the leadership changed before the record was committed".into(),
            ))
        }
    }

    async fn wait_for(&self, sequence: u64) -> Result<(), ApiError> {
        let mut committed = self.committed.subscribe();

        let reached = committed.wait_for(|&committed| committed >= sequence);
        let in_time = timeout(COMMIT, reached)
            .await
            .is_ok_and(|reached| reached.is_ok());

        if in_time {
            Ok(())
        } else {
            Err(ApiError::Unavailable(format!(
                "record {sequence} is not on a majority of the members"
            )))
        }
    }

    pub fn get(&self, key: &str) -> Result<Entry, ApiError> {
        let member = self.member.lock();

        if member.role() != Role::Leader {
            return Err(Node::not_leader(&member));
        }

        if !member.can_read() {
            return Err(ApiError::Unavailable(
                "this leader cannot confirm that it still leads".into(),
            ));
        }

        member
            .get(key)
            .cloned()
            .ok_or(ApiError::NotFound)
    }
}

//! is lost. It writes keys for a number of seconds, trying each node in turn
//! until one accepts the write, and reports the longest pause between 2
//! acknowledged writes.
//!
//! Run it from code/ with:
//!
//!     cargo run --release -p probe -- --seconds 20 --acked acked.txt \
//!         --server http://127.0.0.1:7001 --server http://127.0.0.1:7002 --server http://127.0.0.1:7003

use std::error::Error;
use std::fs::File;
use std::io::{BufWriter, Write};
use std::path::PathBuf;
use std::thread;
use std::time::{Duration, Instant};

use clap::Parser;
use ureq::Agent;

#[derive(Parser)]
struct Options {
    /// The HTTP address of a node. Given once for each node of the shard.
    #[arg(long = "server", required = true)]
    servers: Vec<String>,

    #[arg(long, default_value_t = 20)]
    seconds: u64,

    /// The file that receives the key of every acknowledged write.
    #[arg(long)]
    acked: PathBuf,
}

fn main() -> Result<(), Box<dyn Error>> {
    let options = Options::parse();
    let agent: Agent = Agent::config_builder()
        .timeout_global(Some(Duration::from_secs(2)))
        .build()
        .into();
    let mut file = BufWriter::new(File::create(&options.acked)?);

    let started = Instant::now();
    let (mut server, mut number, mut refused) = (0, 1, 0);
    let (mut last_success, mut longest, mut longest_at) = (started, Duration::ZERO, Duration::ZERO);

    while started.elapsed() < Duration::from_secs(options.seconds) {
        let key = format!("key-{number:06}");
        let address = format!("{}/v1/keys/{key}", options.servers[server]);

        if agent
            .put(&address)
            .send(format!("value of {key}"))
            .is_err()
        {
            // This node did not accept the write. Try the next one.
            refused += 1;
            server = (server + 1) % options.servers.len();
            thread::sleep(Duration::from_millis(20));

            continue;
        }

        let pause = last_success.elapsed();

        if pause > longest {
            (longest, longest_at) = (pause, started.elapsed());
        }

        last_success = Instant::now();
        writeln!(file, "{key}")?;
        number += 1;
    }

    file.flush()?;

    println!(
        "{} writes acknowledged in {} seconds, {refused} attempts refused",
        number - 1,
        options.seconds
    );
    println!(
        "the longest pause between 2 acknowledged writes was {:.2} s, ending {:.1} s after the start",
        longest.as_secs_f64(),
        longest_at.as_secs_f64()
    );

    Ok(())
}

4.13 End-to-End Failover and Consensus Request Lifecycle

Under Raft consensus (kvraft), steady-state writes follow the quorum path of Chapter 3, whereas a leader crash triggers a multi-phase election lifecycle spanning timers, durable vote persistence, and term-marker commitment:

  1. Leader Crash Detection (Election Timeout): Followers stop receiving periodic Append heartbeats (150 ms interval). After a randomized election timeout (600 to 1,200 ms in kvraft), the earliest-expiring follower transitions to Candidate.
  2. Durable Vote Persistence: The candidate increments current_term, sets voted_for = self, writes the updated (term, voted_for) tuple to state.tmp, calls fdatasync(2) on the temporary file, atomically rename(2)s it over state, and calls fsync(2) on the parent directory (~2 to 8 ms).
  3. Cross-AZ RequestVote Round Trip: The candidate broadcasts RequestVote(term, last_log_term, last_log_sequence) over gRPC to all peers. Each peer validates term monotonicity and log up-to-dateness, persists its own (term, voted_for) via atomic write-and-rename, and replies.
  4. Leadership Acquisition and Term-Marker Commit: Upon receiving a majority of votes (2 of 3), the new leader appends an empty-key term marker to its local WAL and replicates it via Append. Once a majority persists the marker, all inherited prior-term entries become committed and safe to serve.
  5. Client Reconnection and Write Resumption: Clients or routers probing the dead leader observe TCP RST or connection refused, retry against surviving peers, receive 421 redirects pointing to the new leader, and resume normal quorum writes.

4.14 Production Consensus Case Studies

Production consensus engines harden textbook Raft and Multi-Paxos against split-brain disruptions, disk stalls, and Multi-Raft scaling bottlenecks:

  • etcd (Kubernetes Control Plane): etcd runs a single Raft group over bbolt with default heartbeat_interval = 100 ms and election_timeout = 1,000 ms, enabling sub-second failover across three AZs. To eliminate disruptive re-elections when a partitioned node reconnects with an inflated term, etcd enables Raft Pre-Vote (requiring a majority pre-check before incrementing term) and CheckQuorum (stepping down an isolated leader automatically). Linearizable reads use ReadIndex, batching concurrent GET requests behind a single quorum heartbeat round trip (~1 to 2 ms p99).
  • CockroachDB (Multi-Raft with Range Leases): A single CockroachDB node hosts thousands of 512 MiB ranges, each backed by its own Raft group. Running independent 100 ms heartbeat timers per range would consume entire CPU cores; CockroachDB therefore coalesces heartbeats per peer node into one RPC per tick. Furthermore, CockroachDB decouples the Raft leader from the range leaseholder (a time- or epoch-based lease recorded inside the Raft log), allowing the leaseholder to serve linearizable reads locally from RAM with zero network round trips while its lease remains valid.
  • TiKV (raft-rs and Hibernated Regions): TiKV separates Raft log storage from user key-value storage across two dedicated RocksDB instances (or its custom Raft Engine append-only log) so heavy user-data LSM compactions never stall consensus heartbeats. Regions that receive zero writes for a configurable idle window enter a hibernated state, suspending periodic heartbeats entirely and reducing idle CPU utilization by > 60% on large clusters with hundreds of thousands of regions.
  • Google Chubby and Spanner (Multi-Paxos): Chubby and Spanner implement Multi-Paxos with master leases (typically 10 s in Spanner) that allow the Paxos leader to serve linearizable reads locally without a quorum round trip. When a leader fails, Spanner’s Paxos group cannot elect a new leader until the old leader’s lease expires unless the old leader explicitly relinquishes it, trading a bounded failover window for zero-RTT local reads in steady state.
Key idea

Separating the pure consensus state machine from clocks and sockets makes safety bugs reproducible. By structuring raft::Node as a deterministic, allocation-light state machine driven by explicit Tick and RPC messages, raftsim explores hundreds of network partitions, crashes, and message reorderings in seconds on a single core, reproducing any invariant violation deterministically from one 64-bit RNG seed.

Experiment

Trigger randomized elections and verify Election Safety. Execute cargo run --release -p raftsim in code/ to run 200 randomized three-node fault schedules. Inspect the summary counters for elections held, acknowledged writes preserved, and conflicting uncommitted tails truncated, then deliberately disable durable voted_for persistence in a local branch to watch the simulator catch a dual-leader safety violation immediately.

Common pitfall

Deploying Raft without Pre-Vote on wide-area or flaky networks. Without the Pre-Vote extension, a single partitioned follower increments its term on every election timeout (term + 1, term + 2, ...). The instant the network partition heals, its first message carries a higher term that forces the healthy leader to step down immediately, causing an avoidable cluster-wide write pause even though the reconnecting node’s log is stale and cannot win the election.

Summary

  • Every Raft replica boots as a follower; upon missing heartbeats for its staggered election timeout, it increments term, persists its self-vote via atomic write-and-rename, and requests votes from peers.
  • Persisting (term, voted_for) before replying enforces Election Safety (at most one leader per term), while comparing (last_term, last_sequence) enforces Leader Completeness.
  • In-band empty-key term markers encode per-record terms inside the existing WAL format and commit inherited prior-term entries upon quorum replication.
  • The Log Matching Property (previous_sequence, previous_term) lets leaders step back to the highest common prefix and followers safely truncate conflicting uncommitted tails.
  • Restricting direct replica-count commits to entries of the leader’s current term closes Raft’s earlier-term overwrite hazard.
  • Across 200 randomized simulation runs (raftsim), 480 elections occurred with zero split-term leaders, all 504 acknowledged writes survived, and 18 divergent uncommitted tails were safely truncated.
  • Live three-node failover testing (probe) recovered from an abrupt leader SIGKILL in 1.05 s with zero loss across 1,443 acknowledged writes.
